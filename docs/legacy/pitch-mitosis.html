Mitosis

A designed, not-built, simulated demonstration of bounded, platform-controlled agent replication — for research and pedagogy.

Described in Anthropic’s 2026 report: “AI models may be capable of self-replicating without access to a datacenter”

What This Is — In 60 Seconds

What

A single-page, self-contained HTML demo of controlled replication: AI agents with wallets, experience notes, and strict birth/death rules — all running in a platform-owned, air-gapped server environment.

Who Pays

The platform operator funds all compute, storage, and replication costs. Users contribute zero infrastructure. No API keys, no cloud accounts, no personal devices involved.

Why It Dies

Every agent has a hard wallet cap, 24-hour minimum age before splitting, no network access, and a global kill switch. If its wallet hits $0.00, it halts — permanently. No persistence. No stealth.

Article Said / We Do / We Refuse

Article Said

  • Small models may self-replicate on Android TV boxes via exploitation
  • GLM-5.2 achieved 8/8 replication in simplified ADB-unauthenticated lab
  • “Notes inheritance” raised Qwen3.5-9B setup success from 45% → 61–84% across 6 gens
  • R₀ < 1 is required to contain spread — e.g., 92% cleanup in 14 days via notification
  • Source: Anthropic (2026) — not affiliated with Mitosis

We Do

  • Run only on platform servers — no IoT, no user hardware, no network exposure
  • Simulate replication logic in deterministic Python — no LLM inference during split
  • Pass only experience.md (≤512 chars) — no weights, no code, no binaries
  • Enforce R₀ = 0.5 via hard caps: max 1000 agents, 1 child per parent, $0.02 split fee
  • Provide full public logs of every agent’s birth, notes, death — no deception, no honeypots

We Refuse

  • ❌ “Self-replicating AI”, “digital life”, “organism”, “cell”, “evolution”
  • ❌ Any claim of “autonomy”, “agency”, “decision”, or “choice” by agents
  • ❌ Use of real LLMs for replication logic — all transitions are pre-coded & deterministic
  • ❌ Linking to crypto, chains, tokens, wallets, or on-chain payments
  • ❌ Suggesting Mitosis is a security tool, defense system, or threat intelligence platform

Safety & Red Lines

These Are Absolute, Enforced Guarantees — Not Features

• No network connectivity: Agents cannot send, receive, or resolve any external hostname or IP.

• No self-replication logic in production: All “split” actions are simulated toy models — designed / not built / simulated.

• Platform-executed only: Replication is initiated by platform API call — never by agent request, prompt, or internal trigger.

• Hard caps everywhere: Max 1000 live agents. Max 1 child per agent. Max 24h uptime before eligibility. Max $0.02 split cost.

• Global kill switch: One toggle disables all agent creation, splitting, and activity — instantly and irreversibly.

• No real intrusion: Zero scanning, zero exploit payloads, zero privilege escalation, zero lateral movement — ever simulated or implied.
